# yaw 滑环装配基准照（主人 09-28 23:0x 手机拍的，我裁了丝印区）

图片：`slipring_yaw_rotor_2026-09-28.png`（我截放的丝印区；原照在他手机上）。
**用途：装配基准。** 以后每次拆装完，拍同一角度一张，与本图比对——**判"装错没"不该靠记性。**

我在这张图里读到的（只看图，不猜）：

- **螺丝端子排没有任何网络标号**（无 `+`/`−`/`CANH`/`CANL`）；丝印只有板号，竖排，可读部分 `…623349A YB14`。
  ⇒ **反接在这里是"无从判断"，不是"手滑"**：任何一根线可以进任何一个孔，板子不给答案。
- 端子排周围有**助焊剂焦痕与阻焊刮伤** ⇒ 端子已被反复施工过。
- 四孔焊盘左侧蓝板上**有一根横细丝**，可能是焊锡鼠须/铜丝，也可能是划线——**未分辨**，
  待主人放大确认。**理由：滑环内部是旋转面，会跑的锡珠比接反更难查。**

**由此定的三条防线（不依赖人的记性）**：
1. 端子排上**自贴标签**（标签纸或漆点，正/负/CAN 各一色），**一次标死**；
2. **24 V 与 CAN 分用在不同端子块**（图里已经分开了，右下那块铜皮更宽＝大电流路径），
   并在 24 V 那头放**保险丝**——真接反时**炸保险丝，不炸驱动板**；
3. **只读上电自检**：先确认 `0x204+id` 反馈帧跑在 1 kHz、总线错误计数为 0，**才允许任何命令发出去**。
   **CAN 接反的症状就是"完全不见反馈"**，所以这条对信号类接反是决定性的；电源类接反靠第 2 条兜。
