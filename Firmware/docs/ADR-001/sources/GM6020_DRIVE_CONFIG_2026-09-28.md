# GM6020 电调内参数（主人 09-28 23:2x 截图，RoboMaster Assistant v2.7 build 73）

图：`gm6020_assistant_v2.7_parameters_2026-09-28.png`。**这是电调自己的配置记录**，
WP6 的单轴辨识与停止包络必须知道驱动侧被设成什么，否则主机侧算得再准也是在猜。

**我从截图里读到的（我眼过，不是主人说）：**

| 项 | 值 |
|---|---|
| 电调类型 | GM6020 |
| PWM 模式 | **位置模式** |
| 最大转角 | 360 |
| 中点位置 | 4096（范围 0..8191） |
| 位置环 P / I | 80 / 0 |
| 速度环 P / I | 64 / 100 |
| **转速限制** | **60 rpm**（范围 0..300） |
| 数据反馈频率 | **1 kHz** |
| 电流环 P / I | 1000 / 500（DJI 默认） |
| **电流环开启/关闭** | **开启** |

**四条判读：**

1. **`电流环开启 = 开启`** —— 这就是 22:3x 复测"电流帧被忽略"缺的那一样。
   **前提：要点右下角"设置"写进电调**，界面值不等于已生效；生效与否**以我重跑探针为准**，不以界面为准。
2. **`数据反馈频率 1 kHz` 与我的实测互相印证**：刚才静置窗实测每秒 1001 帧反馈。文档说 1 kHz，配置说 1 kHz，总线上的数也是 1 kHz——**三方一致才叫印证**。
3. **`转速限制 60 rpm` 是新事实，且会改写一条旧发现的解释**：今晚 yaw 的 A/B（`max_output_counts` 6000）没看到饱和事件，
   我当时记成"未定论"。现在多一个候选解释：**驱动自己就把转速帽在 60 rpm**，
   所以"主机侧限幅没触顶"可能压根不是我们的配置问题。**旧结论不动（仍是未定论），候选解释登记在此。**
4. **`PWM 模式 = 位置模式` 我认为不适配我们这套代码**，理由两条：
   ① 我们的主机侧已经闭位置环，驱动内再闭一层是**双环互相较劲**（今晚电压帧只让编码器走 2 个字，与此相符）；
   ② `最大转角 360` 对**连续旋转的 yaw（有滑环、机械无限位）**是错的形状——它把无限轴关进了 360° 的笼子。
   **建议改成电压模式**（与今天的实际行为一致），电流环验证时再看该用哪一档。**这是他的板，我只把理由摆全。**
   PID 三组参数按裁决（PID 调教排在 ADR-001 之后）**我不动也不评**。

## 第二张（同分钟，`…_b2.png`）：转速限制 **60 → 300 rpm**

其余项一字未变。`0..300` 是量程上限，**所以这不是"设了个转速帽"，是"把驱动侧的转速帽摘掉"**。
⇒ **从今天起主机侧限幅是唯一体面的防线**，而 yaw 那条 `max_output_counts: 15000` 的管道**至今未现场验证**。
⇒ **我不许自己现在拿 300 rpm 做全速试验**；WP6 单轴辨识时再定一个**有测量依据的帽**，
   今天他这一步的价值是：**摘掉帽子之后，之前那个"未定论"的 A/B 才有重做的意义。**

**另一处我看见了但不敢判**：第二张里 `电流环开启/关闭` 那格底色发灰（第一张是白底可编辑）。
**灰色在这个界面里是什么意思我不知道**——可能是"已写入锁定"，也可能只是焦点态。
**不当结论用，待主人确认或点一次「设置」。**

## 主人更正（09-28 23:3x）：**PWM模式那一档是给 PWM 输入用的**

原话：**「pwm只有速度模式和位置模式，是给pwm输入用的」**，且**没有"电压模式"这一档**。

⇒ **我上面第 4 条判读作废**：`PWM模式=位置模式`、`最大转角 360`、`中点位置 4096`、`位置环 P/I`
   **都是 PWM 输入通路参数**，我们全程走 CAN，**这一整块对我们是无关项**，不是"不适配"，是**不相干**。
⇒ **连带作废**：我拿"驱动内双位置环较劲"去解释今晚那条电压帧只让编码器走 2 个字——**解释候选错了**。
   重列，按可能性排：
   1. **命令本身太小**：`raw 3000` 在文档量程 ±25000 上只有 **12%**，一根带摩擦的连续轴不动很正常；
   2. 载荷/摩擦/水平安装的重力分量；
   3. `转速限制 60 rpm`（当时还在）——**但 2 个字/9 rpm 远未触顶，解释力弱**。
   ⇒ **对 WP6 的直接影响**：单轴辨识**必须从"多大命令才开始动"往上扫**，不能拿一个小命令判"响应迟钝"。

**这一屏真正与我们有关的只剩三项**：`电流环开启`（须写入电调）、`数据反馈频率 1 kHz`、`转速限制`（现 300＝摘帽）。
**其余都别动。PID 按裁决不评。**
