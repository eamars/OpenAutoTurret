# 05 · 3a与3b的双实机验收

## 1. 两个门槛不可替代

**3a**：真实设备上运行独立commissiond，验证实际共享core、当前候选与模型。只做软件仿真不算3a。

**3b**：真实设备上运行实际production executable，使用正常命令/参考/限幅/core/backend/停止链，运行完整正常服务负载。只在production中加载文件、回放日志、shadow计算或旁路原链均不算3b。

两者必须绑定相同hardware、measurement、plant、candidate/profile、core-build、observer、metric与工况域。不同二进制不是问题，但实际有效算法/core构建和参数相同是必要条件。任何一方params改变后旧证书失效。

3b证书必须引用本次完整3a证书hash，并且开始时间不早于3a结束；两证书须有带时区的可靠开始/结束时间，时间有效性由实际日志验证，不能补写虚构顺序。

每个轴、每个必须工况、每个必需case都需3a和3b结果。通过不能由平均值掩盖一个方向失败。两环境各自达到绝对指标，并检查production额外劣化，不能只证明相对上一版变好。

## 2. 3a规定内容

实际加载读回；响应/平滑/反转/小位置运动/停止；多角度/方向/另一轴姿态；模型自由预测与实际一致；输出约束与真实故障路径；原始encoder、gyro、accel覆盖。

恒速段至少2秒且最终参考达到平台；低速3/5°/s、代表10°/s仅在原范围已允许时执行。约定完整范围缺许可不是PASS而是BLOCKED；不得自行删掉该case。位置阶跃0.5/1/5°在批准区间内经真实整形器执行；每格重复3次，报告每次/最差值，不伪称可靠性p95。

角度网格与控制表一致；三种另一轴姿态来自批准范围内低/中/高。双轴同时运动必须有独立组合轨迹，不能以两轴分别成功推出组合成功。

## 3. 3b规定内容

### 3b-I：确定性生产参考链

通过production既有合法命令入口输入同一冻结轨迹，经过正常reference manager、v/a/j、模式/guard、shared core与真实motor backend。辨识台架不可持有输出。记录上层请求、接受参考与最终内环参考。

如果业务接口不能表达该轨迹，新增有鉴权的测试命令入口可用，但必须进入生产reference链的顶部，不能直接写motor backend。运行时数据验证其路径标识；该入口不得删除业务链限制以换取PASS。

### 3b-II：真实负载及生命周期

相机/IMU/网页等正常进程同时运行，在正常服务运动路径运行；保留视觉/通信负载，但不修改检测/目标逻辑。完成启动、归零、归零结束到current服务、模式变更、停止、参数加载/重启及非测试轴支撑。

真实服务轨迹可能与合成轨迹不同，分别报告，不混成同工况对照。3b-I负责严格路径比较，3b-II负责实际生产负载与生命周期。两个部分都是3b必需项。

## 4. 冻结的质量目标

下列是本ADR设计目标，延续旧ADR的低速量级并补齐模型和生产一致性；不是现场性能事实。[P1,P2]

| 类别 | 目标 |
|---|---|
| 实际跟随 | 恒速平均实际/参考=0.90–1.10；连续运动比例≥95% |
| 低频速度误差/抖动 | RMS分别≤max(0.5°/s,参考绝对值×10%) |
| 位置残差jitter | 去恒速趋势的P95−P5≤0.15°，完整峰峰≤0.30° |
| 停止漂移 | 从实际零参考开始的固定2秒窗最大漂移≤0.15°；另报减速距离/时间 |
| 位置响应 | 稳态误差≤0.15°；过冲≤max(0.15°,阶跃10%)；0.5/1°运动在1秒内进入并保持误差带，5°单列按真实整形器计算截止 |
| 起动 | ≥5°/s请求下成功TX到持续运动确认最大值≤200ms；同时报原始初动，不能仅3计数通过 |
| 模型独立验证 | 留出角度预测RMS≤0.15°，速度RMS≤上述误差目标，且明显改善仅保持/常速预测基线；基线本就合格时不强迫百分比提升 |
| 数据能力 | 有效噪声不超过对应目标1/3，采样/时钟可解析目标；不足为MEASUREMENT_LIMITED，不加大阈值 |
| 生产一致性 | 3b达到同一绝对目标；同case指标不得比3a恶化超过max(3a值×10%,该指标目标×10%)，不足报告INTEGRATION_MISMATCH |
| 热/供电 | 有效测量、代表性负载达批准温度/母线/电流边界；热平衡按连续两个10min窗口温升斜率绝对值<0.1°C/min且保有批准裕量检查，最少观察30min不等于自动通过 |

1秒位置稳定时间从**命令被正常生产入口接受**开始，另报reference shaping完成后的控制误差收敛；不能移起点隐藏整形延迟。5°的通过截止在冻结轨迹生成时由其加速度/jerk/速度与≤1秒收敛余量算出，不能运动后调整。

低频估速使用固定200ms局部线性窗口以延续002.1可比性；但它不是唯一jitter指标。所有gyro在有效0.5Hz至min(20Hz,有效采样率/5,已校准带宽)的角速度振动RMS也须≤上述速度抖动门槛，并报告PSD与峰值频率。有效带宽不足不得声称20Hz以上没振动；encoder位置残差和原始accel冲击记录独立保留。accelerometer主要检验冲击/振动与模型一致性，不把m/s²阈值生搬成°/s²。

质量超标结束当前验证，不自动掉电；真实危险交保护处理并结束校准。受控降额后未满足原性能目标仍为未通过，不改目标。

## 5. 必需的变化验证矩阵

至少以下六个实际、可追溯工况：BASELINE、PAYLOAD_UP、PAYLOAD_DOWN、FRICTION_UP、FRICTION_DOWN、RETURN_BASELINE；外加一个不向辨识器声明标签、但有操作者独立记录的UNDECLARED_CHANGE验证变化检测。

变更大小由批准的机械作业/试验包络确定，需记录质量/重心或实际响应差异，不能所有标签实为同一设备数据。摩擦变化不要求危险破坏轴承：只允许批准的可逆摩擦/预紧设置或工装；没有可重复摩擦变更条件则该必需资格BLOCKED，不以仿真代替实机PASS。

每个发生参数更新的工况独立3a→3b；同参数确实复用也要有对应当前工况的证据。记录从声明/检测到识别、模型通过、3a、3b、正式恢复的时间与实机动作次数。自动更新最多2轮定向补测，不靠agent手选Kp。两轴都覆盖，因为pitch载荷也影响yaw。

每次变化均证明：无改源码/重编译/人工参数选择，阶段1/2方法hash保持；复用了哪些旧资产、更新了哪些快照；变化过程中最大误差/停止行为/热边界。禁止只保留稳定后的最后两秒。

## 6. 晋升与证据的含义

`PASS_BENCH`不能创建active production profile。只有同一snapshot的3a和3b全覆盖、没有未解释HARD_ABORT/无效数据、实际readback一致，且已有晋升权限成立，才原子更新active指针。

证书必须包含实际软件路径/核心构建、硬件和工况身份、case集合、每项指标与原始数据hash。参考validator只是检查结构和一致性；不能从一个JSON的`physical=true`数学证明真的运行了设备，必须与原始日志、launcher和现有审计链绑定。

“程序完整性完成”与“某工况无法满足物理要求”可以分别陈述；但本ADR的最终DONE必须满足所约定工况矩阵。缺证据/能力限制不能改名为完成，更不能编造数据。
