# 04 · 实际反馈、数据资产与自动更新

## 1. 完整反馈，不只jog摘要

所有数据具备hardware/control/measurement/operating_point身份、单调时钟、源序号、generation和有效性。采集从刺激前至少2秒开始，覆盖整个运动与规定停止窗；禁止末尾滚动11秒替代全程。

| 流 | 必需内容 |
|---|---|
| 执行输入 | requested、limited、successful_TX、模式、实际readback、owner epoch、命令序号 |
| encoder | 原始计数、去回绕位置、输出轴映射、RX序号/时间、源generation |
| 电流/状态 | 原始值/换算值/单位/有效时间、Iq/iqf来源与滤波、母线、温度有效性、错误增量 |
| IMU | 原始gyro/accel/quaternion（可用时）、采样和接收时刻、安装标定、bias、tare/generation |
| core | 各级q/v/a参考、观察器状态、PI误差/积分、前馈各项、起动状态、限幅原因 |
| production | 应用模式、参考产生/接受时刻、队列/调度、其它生产负载、最终TX |

request电流、CAN成功发送电流、实际电流测量不是同一事实。IQ采样间断时模型必须处理实际采样/滤波；不能用last-value重复填满200Hz后称实测200Hz。

## 2. 一次建立、条件复用的反馈资产

第一次获得一个H/C下的数据后，存不可变raw run、标定、响应索引、valid frequency band、角度/方向覆盖、breakaway区间、拟合与不确定性。后续优先从这些资产中回答问题。

phase2的采集器/拟合器/原始历史不随payload变化重做。旧参数只在残差检查/适用域允许时复用；新snapshot引用所用旧数据与新增数据，不能把历史数据全标过期后每次大扫描。

## 3. 必需的信号设计器

不是PID候选设计器。信号类型固定为：静止噪声/时间验证、局部有界起动电流斜坡、双方向连续运动与加减速、带限多正弦/平滑扫频、规定的参考阶跃/反转（后两项闭环验证）。

具体幅度、持续时间、空间范围由**当前批准包络＋已有模型预测＋信息量**计算，不能在文档里凭空给一个可安全施加的电流。初始包络来自现有可验证许可；不存在则BLOCKED_ENVELOPE。所有有效包络均由实际硬件/工况证据限定，不因用户希望最大输出而取消。

从固定的32个归一化辨识轨迹模板预测Fisher信息矩阵，选择预期单位占用时间内log-det提升最大的可行刺激，按case_id打破平局。a/b信息不足选择加速度/速度激励，h缺项选择对应角度/方向，时延不确定选择有效带宽内的动态激励。

**2026-09-30 主人更新：** yaw首次测量从当前工况适用的最大持续电流开始；pitch首次刺激建议约2 A，具体由其已批准工况包络确认，当前仍先完成yaw。需要不同运动区间的数据时，初始幅度采用固定比例(1, 1.5, 2, 3)向下变化，而不是寻找最小电流。30度仅为提示，不是统一采集资格门槛。电机额定/最大持续电流与持续堵转电流的工况区别保留；未知Iq或反馈单位换算必须显式记录，不以假定换算伪造物理资格。

采集完成后，以实际时间上的编码器运动和独立IMU旋转共同验证实体实际运动，保留与静止噪声及量化的比较、持续时间、速度/加减速和方向覆盖。无实际持续运动或信息不足是采集结果，必须驱动后续测量或明确能力不足，不能凭进程成功退出推进拟合、控制器资格或阶段3。该判定不新增行程/速度arming门槛，也不因噪声自动结束物理采集。

只用该选择器产生主动补测；不允许agent按文字输出挑刺激。归一化模板不是直接硬件命令，执行前必须证明整个动作及停止可置于批准范围。未知惯量/停止能力不能由预测器假设已安全。

最多2轮新增信息补测/同一变化事件，每轮选择最多3个信息case；数据采集失败只允许相同case重试1次。预算耗尽报告信息/模型/能力不足，不接着手调。初次覆盖矩阵按批准空间与两方向完整执行，不受这个局部更新预算冒充覆盖。

## 4. 参数变化与事件触发

监测层按2秒有效窗口计算白化模型残差、跟随、输出受限比例与工况映射。窗口内至少覆盖评价频带所需采样；不是只取200Hz控制tick数量。

变化检测默认：连续3个有效窗口的白化残差RMS > 2（残差按阶段2实测噪声/预测不确定性归一化），且不是参考变更、保护干预或传感器失效解释的现象，产生CHANGE_DETECTED。显式payload/摩擦事件立即建立新operating_point，不等待残差阈值。该统计阈值是设计约定，不是通用故障极限。

事件输出是重新辨识请求，不是立即在线修改gain。生产处于已授权校准窗口时自动进入独立程序；否则只监测并报告/限制不可达参考，不擅自打断任务或启动硬件动作。人只负责物理变更与授权，不负责选参数。

## 5. 自动更新的固定分支

```
确认输入/测量有效
  → H/C不兼容：只失效相关资产，阻断使用
  → 相同O且旧snapshot预测合格：直接复用
  → 已覆盖O：选旧模型或在可信域内插值，重新计算不确定性
  → 新O/残差变化：同一辨识器用近期新数据更新
       → 信息不足：信息选择器定向补测
       → 模型合格：计算一个新候选 → 3a → 3b
       → 模型不合格/预算耗尽：明确失败，不扫PID
```

每个候选有独立data provenance和hash。跨工况合并只限被验证为不变的参数，摩擦和温度变化不能通过遗忘因子把错误悄悄抹平。动态事件期间全部瞬态保留，用于适应性验收。

## 6. 热与供电

没有有效温度就不能声称热平衡或长期最大电流已合格。可以继续已批准的有限台架证据，但最终热/生产要求仍未通过。电流上限、持续时间和散热证据绑定O；过去某个payload热稳定不是所有payload热稳定。

最大合格电流可以充分使用；目标函数不惩罚电流大小。预测需要超出包络则ENVELOPE_LIMITED，不自动提高电流或延长占空。仅降低需求若不能满足约定验收，就报告未通过，不能偷改用户目标。

## 7. 参数切换与回退

新snapshot通过3a后可在受监督3b会话中以candidate身份加载；只有3b通过才更新正式指针。切换时停在已验证可无扰状态，计算积分衔接，读回全量值。失败恢复适用于当前O的已验证profile；若没有这种profile，则按当前可控能力受控停车/支撑，不盲回旧载荷参数。

程序允许恢复到已知payload复用历史snapshot，但必须核对机械/摩擦没有同步变化。摩擦调整或增减payload在停稳且支撑妥当时进行，不要求操作者接近运动轴。
