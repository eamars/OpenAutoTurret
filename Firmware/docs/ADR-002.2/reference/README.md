# 离线参考实现：功能边界

本目录仅提供可以执行并测试的三个窄组件：

1. `model_math.py`：常a/b、分方向常负载的积分回归初始化；理想PI公式与精确ZOH离散闭环极点检查。
2. `contracts.py`：canonical hash、资产复用判定、两环境证据绑定/覆盖/真实路径声明检查。
3. `demo.py`：从合成响应验证上述工具和3a-only拒绝；不访问硬件。

**这些不是完整自动整定器。** 位置/姿态表、输出误差模型拟合、信息量信号选择、真实IMU标定/观察器、128模型鲁棒求解、共享C++core、commissiond/production adapter、实时保护和实机验收均是Codex必须完成的合同项。

完整功能没有被定义为“下一版”；只是本开发包不是用户仓库的已实施固件。reference中的简化模型不得以更名方式替代docs规定的完整功能。

使用环境与实际测试结果写入reports；仅依赖numpy/scipy，schema检查用jsonschema。项目集成时按其已锁定依赖环境使用兼容版本，不能因参考工具可运行就更新整项目所有依赖。
