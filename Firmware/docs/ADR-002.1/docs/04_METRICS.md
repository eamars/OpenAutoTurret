# 04 · jitter、跟随与数据有效性

## 1. 为什么不能只设一个 jitter 数字

一个几乎不动的轴可以有很小的速度方差。U1 的实际参考约 3°/s，而若干工况速度远低于该值；这类候选无论 jitter 多小都不能通过。

U1 的三计数约 0.132°，即每计数约 0.044°。按此近似，20 ms 一计数的差分速度步进约 2.2°/s。这个数量级接近 3°/s 的目标，因此不能直接把 20 ms 差分的颗粒度当成全部机械抖动。此处是由报告数值计算的量化尺度，不是重新校准编码器。

## 2. 固定输入和评价器

primary：有真实 RX 时间戳、去回绕且去重的编码器位置。最终参考取内环实际 be_cmd；vref 保留诊断但不能替代。

每个恒速段独立评分，不把正负动作合并，不包含加减速。raw q 不按候选改变滤波。离线速度 `v_hat(t)` 使用固定 200 ms 局部线性拟合斜率；窗口内至少 5 个独立样本，覆盖至少 150 ms，两端没有完整窗口的点不计。此评价器不部署成新控制器。

重复 RX 样本只保留一次；同一时间戳给出不同 q、非单调时间、非有限值、单位缺失或跨时钟未对齐都使数据无效。日志 tick 不是独立 RX 帧。

## 3. 恒速主指标

在恒定参考 r 的有效稳态段，拟合 q(t)=a+b*t，残差 x=q-(a+b*t)。

- `Jq = P95(x)-P5(x)`：位置残差的稳健峰峰值；另报告 max-min，避免稀少尖峰被忽略。
- `Jv = RMS(v_hat - mean(v_hat))`：固定离线估速的波动。
- `E_v = RMS(v_hat-r)`：包括速度偏差的跟踪误差。
- `tracking_ratio = mean(v_hat)/r`：正反方向都应接近 1；r=0 不使用这个量。
- `active_fraction = fraction(sign(r)*v_hat >= 0.5*abs(r))`：持续运动比例。
- `stop_drift = max(abs(q_hold-q_hold_start))`：停止后固定观察窗内的最大漂移，不以正负抵消。

减掉线性趋势只用于区分 jitter；tracking_ratio 和 E_v 不去趋势。因此静止/匀速爬行不能利用去趋势获得 PASS。

## 4. 本版冻结的初始质量目标

| 指标 | 冻结目标 |
|---|---|
| Jq | ≤0.15° |
| 残差完整峰峰值 | ≤0.30° |
| Jv 与 E_v | 各自≤max(0.5°/s, abs(r)×10%) |
| tracking_ratio | 0.90～1.10 |
| active_fraction | ≥95% |
| stop_drift | 2 秒固定停止观察窗内≤0.15° |
| 有效恒速数据 | ≥2 秒；最终参考确实为指定平台 |
| 有效采样 | 已去重；相邻 primary 样本间隔≤50 ms；完整覆盖分析窗 |

这些数值是要求，不是声称设备已达到。0.5°/s/10% 与停止漂移量级继承 P1；位置 jitter、采样和持续运动条件是本版新增设计。高于门槛可以淘汰候选，但不得让优化器把门槛自动放宽。

10 秒静止基线用于测量能力检查：`Jq_static <= Jq_limit/3`、`Jv_static <= speed_limit/3` 且编码器一步不大于 Jq_limit/3。未满足标为 MEASUREMENT_LIMITED，不能通过抬高 jitter threshold 掩盖，也不能据此断言机构一定振动。热资格未取得时单列 NOT_RUN。

在线淘汰可以在已经形成完整有效窗口后判定：连续两个评价时刻（间隔 0.5 秒）任一 jitter 超过目标 4 倍，正常结束该候选。它是效率策略，不替代即时硬保护；未得到有效窗口前不可宣称零 jitter。

## 5. 停止窗口与数据处理细节

停止观察窗从最终参考到零且进入本次定义的结束阶段开始；报告运动结束到窗口开始的延迟。必须保留整个减速段，但不将减速中的必要位移全部标成保持漂移。出现长时间无法完成受控结束由既有保护链处理，不靠推迟 hold 标签隐藏。

参考工具对已标为 hold 的连续段精确截取前 2 秒，插值边界只在小于采样间隔上限的相邻样本之间进行；额外更长观察单独报告，不将不同长度窗口混比。

## 6. 统计与有效性

baseline、coarse 和 confirm 是不同证据等级。confirm 每格仅 3 次，使用全部实测值与最差值判定，不称其为 p95 可靠性证明。

失效 trace、应用失败、姿态不符、参数变更或温度组不符的试次不能参与排名。未完成的结果不是 FAIL_QUALITY，而是 INVALID_DATA/NOT_RUN。

IMU 默认为辅助证据，不作为上述 primary 通过的必需输入。报告必须说明是否有完整重叠、是否安装标定有效；未标定时只报告传感器空间观测，不命名为机构 yaw/pitch。
