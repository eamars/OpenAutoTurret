# ADR-003：相机快速跟拍的目标预测与双层前馈／反馈

- 日期：2026-09-30。
- 状态：设计已明确；尚未实现或实机验收。
- 位置：`Firmware/docs/ADR-003/`。
- 输入：用户研究稿[R0]、相机取景用途确认[R1]、当前分支必要控制逻辑[S01–S24]。
- 范围：固定基座、当前选定相机、单一已选拍摄对象的两轴连续跟随。允许当前相机的既有预览／拍摄负载；不增加跨摄融合或新目标识别能力。
- 下文“决定”均为本ADR设计，不冒充源码现状或实测性能。来源索引见[sources/SOURCES.md](sources/SOURCES.md)。

## 1. 背景与问题

研究稿要求把目标运动前馈与电机模型前馈分开，支持静止、匀速、加减速、急停、反转、延迟和丢帧，并坚持纯数学阶段与双实机验证。[R0 §§1–22]

当前实现已经具备曝光时刻电机姿态历史、像素转基座LOS、CV Kalman及显式目标速度送入`track_reference`。因此问题不是“缺少一切预测”，也不能凭阅读源码就断言所有现场迟缓来自同一处。[S04–S08]

本ADR处理的具体缺口是：

1. 曝光／处理／控制／执行的时间需要明确分账，不能用一个固定提前量代替测量。
2. 同一目标运动状态目前经过多个对象取值；需要把角度、速度、时间和有效性作为一个契约传递。
3. 最终位置、速度、加速度必须出自唯一轨迹状态，不能使用遥测差分代替控制参考。
4. 目标估计噪声、参考响应参数需由数据及模型求解；不能继续现场逐个试数。
5. 取景结果应以实际曝光时的画面位置、运动拖影与首次可用画面评价，不能只看电机控制周期。

## 2. 决策摘要

**保留并完善现有级联，不增加第三层“万能PID”。**

```text
实际相机帧／既有检测与目标选择
                 │ 相同图像的观测时间、坐标、身份、质量
                 ▼
曝光时刻相机姿态 + 相机内参／外参
                 │ 已消除相机旋转的基座LOS观测
                 ▼
TargetEstimator：一个CV Kalman，输出带时间的目标角度／角速度
                 │ 查询本控制时刻与执行时刻的状态副本
                 ▼
AutoTrackController：沿用的选择／coast／lost政策，无控制数学
                 ▼
ReferenceManager：唯一来源裁决、LOS→连续关节分支
                 │ TrackingGoal{q_target, v_target, 时域, 有效性}
                 ▼
Level 1：目标运动FF + 目标至参考误差FB
                 │ 复用并扩展track_reference / ReferenceLimiter
                 ▼
唯一 ReferenceSample{q_ref, v_ref, a_ref, t_ref, constraints}
────────────────── ADR-003 / ADR-002.2 边界 ──────────────────
                 ▼
Level 2：ADR-002.2共享axis_control_core
   已辨识物理模型FF + 位置P／速度PI反馈 + 最终输出限制
                 ▼
既有motor backend → 电机 → 编码器／已标定IMU反馈
```

固定基座坐标系不是磁北／全球世界坐标，也不意味着IMU提供绝对姿态。当前pitch组件上的IMU只通过ADR-002.2的测量契约提供有效的机构姿态／速度，不再建设一套融合器。

## 4. 两级反馈如何避免重复

以同一连续关节分支说明：目标的期望关节方向为q_t，参考为q_r，实机为q_m。

`总取景误差 e_total = q_t − q_m`

`参考误差 e_track = q_t − q_r = e_total − (q_r − q_m)`

`伺服误差 e_servo = q_r − q_m`

Level1修正e_track；Level2修正e_servo。实际画面误差始终记录并用于能力／参考领先检查，但**不把同一e_total同时送进两个位置控制器**。

这是对研究稿示例`ω_cmd=ω_target+K_track e_LOS`的明确替代，并非忽略位置反馈。研究稿允许选择与既有生成器更适配的公式。[R0 §2] 理想电机q_m=q_r时，e_track就是实际取景误差；真实电机不理想时，其执行残差由002.2负责，不让上层重复补偿。

Level1的未限幅形式为：

`a_request = 2 λ v_t + λ²(q_t−q_r) − 2 λ v_r`

其中第一项是目标运动前馈，其余是参考误差和速度阻尼反馈。经同一个约束与积分器输出q_r/v_r/a_r。加速度前馈不存在，绝不把0伪装成已经估得的目标加速度。

Level2保留002.2已规定的位置P、速度PI、物理前馈及最终抗饱和。研究稿的直接PD公式仅是示例；不得据此删掉已接受的002.2积分或另建一套PD。目标运动前馈关闭不影响该物理伺服的存在。

## 5. 静止、机动和丢失

静止时，可靠估计的目标速度趋零，Level1前馈随之趋零；参考误差将参考拉向目标，Level2维持该参考。必要静态支撑电流仍由002.2决定，不能为了“静止FF为0”把承重补偿删除。

加减速／反转时，由新观测创新更新速度和不确定性，参考生成器产生实际需要的加速度与jerk。固定的过程噪声适应规则处理机动，不增加“运动控制器／静止控制器”切换。CV不能在观测到来前知道任意急停，验收必须包括不可消除的感知时延而不宣称零延迟。

目标速度不可靠、位置仍可信时，只削弱运动FF与相应预测，位置反馈继续。完全失去目标后，有限时间内预测并衰减；超限进入既有LostHold。重新出现时在身份一致条件下重建可靠速度，不携带另一目标的运动状态。不把目标丢失视作电机故障。

明确选中的摄影对象不能因丢失被悄悄替换成另一个对象。现有自动漫游的外层业务政策不在本ADR重写；跟踪模块自身不能发起漫游。

## 6. 延迟与快速取景

分别记录：光学观测→metadata、推理／解析、选择、发布→控制接收、接收→被使用、控制→成功TX、TX→物理响应、曝光时画面误差。各段来自同一帧／命令链，不能把各段p99直接相加当端到端p99。

当前配置120 ms只是配置事实，不是新的实测纯延迟；当前代码已有200 Hz控制与latest-only预览，不重复“优化”已经存在的机制。[S04,S10,S13]

提速顺序固定为：消除错误时间语义和无用排队 → 使用完整目标运动状态 → 计算合适参考响应 → 验证实机执行。禁止先盲加预测时长、提高电机gain或升主循环频率。

已确认选中的新鲜观测可立即启动位置收敛，速度FF初始为0，待速度可靠后连续加入；不再叠一段没有独立证据作用的固定50 ms等待。仍未确认的检测不绕过既有选择确认。相同帧在多个控制tick被读取不算多帧确认。

## 7. 复用与实现范围

新增逻辑只需一个可由独立宿主与生产共同链接的`tracking_core`构建目标；它是现有跟踪类的可测试组合，不是新daemon或第二个数学实现。尽量在当前文件中完成局部扩展。

必要改动位置及单一职责见[01_SOURCE_AUDIT.md](docs/01_SOURCE_AUDIT.md)。必须删除本跟踪路径重复的提前量／重复轨迹导数使用，但不开展全仓库命名、旧分支或模式重构。

观察时间语义确需扩展时，native observation一次版本化；沿用现有二进制codec和跨语言golden测试。旧58字节协议不作为ADR-003完整性能资格的默认输入。不另做协议框架或双写长期兼容平台。

## 8. 阶段与完成标准

阶段1在没有Pi／摄像头／实机日志时完成数学、接口、信号生成和14个合成场景。阶段2测量与复用时间、相机、噪声和002.2物理资产，程序求解参数并自动注入。3a与3b同参数、同核心实机通过，且实际摄影范围及测量分辨力满足冻结要求。

源和算法不变、硬件与适用域一致时复用1／2；换payload由002.2更新相关物理资产，003复用目标估计方法，仅重算受到带宽变化影响的参数并双验证。换相机模式／焦距／观察延迟则只更新相关视觉资产，不重辨识整个电机。

## 9. 故障隔离

沿用已有处理：无效观测拒绝、陈旧目标有限coast、身份改变重置目标状态、范围外受控保持、真实电机故障交002.2。模型参数不可用时仅在已有证据证明反馈独立可工作时关闭该FF；不能无条件撤掉维持pitch所需补偿。

不要求为所有假想故障开发新恢复流程。新增强制测试仅服务研究稿14个场景和明确的时间／身份／轨迹接口不变量；保护系统本身不重建。

## 10. 替代方案与代价

| 方案 | 本次决定 |
|---|---|
| 全面改成CA／IMM／神经网络预测 | 不采用。现有CV已具备所需基本结构；先正确对时、去自身运动、拟合噪声并验证机动响应。若约定指标无法达到，报告模型能力缺口，不自动追加算法。 |
| 原始pixel速度直接前馈 | 不采用。坐标与相机自身运动不分离。 |
| 保留固定120 ms并手动调大 | 不采用。时延与动力学混淆，急停／反转可能恶化。 |
| Level1直接向CAN发更快命令 | 不采用。破坏002.2、参考一致性和输出所有权。 |
| 两套静止／运动控制器 | 不采用。额外切换且重复调参。 |
| 全量新轨迹库／MPC | 不采用。复用小型生成器、统一状态并补足一致性即可；当前证据未要求新规划平台。 |

代价：短时CV预测无法预知任意突变；快速运动的可达范围仍由相机时延、测量噪声和002.2能力共同限定。角度不等于世界3D位置；近距离相机平移视差只在校准证明其误差可忽略的摄影范围内接受，不用一个相机虚构深度。固定基座不涵盖移动载具惯性稳定。

## 11. 参数、接受标准与证据

本包不给未经测量的最终响应、误差、帧率或成功率数字。按摄影要求和实际成像几何建立接受阈值，按反馈数据求解算法参数，两者不得互相替代。

摄影要求未知时保留模板null；不能根据某次测到的坏结果把容差变宽。合成场景可用明确的测试数值，但不作为硬件资格。全部计算与验收方法见[数学与接口](docs/02_MATH_AND_INTERFACES.md)和[阶段与验收](docs/03_STAGES_AND_ACCEPTANCE.md)。
