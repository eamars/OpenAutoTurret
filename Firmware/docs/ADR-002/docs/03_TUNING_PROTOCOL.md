# 03 · 有限、可回滚的分轴调试协议

这里的数字是**建议初始试验条件/验收目标**，不是硬件已实现值；现场有效边界优先。所有硬件动作需操作者确认测试区域、承重支撑与当前会话。开发包本身不授权自动activate、重刷固件或启动自动巡航。

## 0. 基线固定

在现有工作区保存HEAD、dirty diff、两份配置、实际部署release、启动有效参数及电调模式/版本。只读必要文件；不clone另一份全库。使用AGENTS和STATION_OPERATIONS规定的launcher；先核对当前CLI --help，不能把文档提议的命令当已实现。

停止编译占用站台：宿主机做x86_64通用测试和arm64编译，硬件测试只在Pi。Pi编译不是物理验收。确认24V/5V、CAN、温度和承重机构处于可测条件，但不要因历史曾欠压便宣称现在仍欠压；也不要因旧短测正常便授权最大电流。

先在源级修复明显的输出竞争，再进行后续gain试验；保留修复前日志/离线回放作为诊断基线，不为抓“原始现象”重新部署已知可能让承重轴掉电的版本。

## 1. 无运动与低能量检查

验证实际yaw current模式0x1FE、槽位/方向、0.8A当前上限；pitch实际RunMode、LimitCur<=5A及gain读回。GM的0x2FE不做在线“试错自动探测”；已有本机0x1FE证据优先。零电流不当作刹车测试。

采集至少一段10s静止数据：实际每轴RX帧计数增量、周期分布、速度估计噪声、温度、Iq基线。由同一控制器保持非测试轴，禁止两个CAN发送者。静止数据用于设运动确认阈值，不用于证明热平衡。

## 2. Yaw独立速度与起动试验

### 2.1 先测试参考，不先改PID

查看v_ff、位置校正后、所有限幅后、最终TX对应的参考。区分“参考本身按15°/s²慢升”和“参考已上去电机仍不动”。确认guard不再穿插零流。记录控制输入→first accepted command→原始编码器移动→算法确认移动，不将几种延迟合并。

### 2.2 摩擦测量

在允许的狭小运动区域、多个yaw角度及pitch姿态，双方向各重复至少5次。让同一闭环commissioning路径以有界斜率增加所需电流，保留速度/位移/时间/温度限制；不要让外部脚本越过controld直接发送无限恒流。

记录：初动电流、保持匀速的电流、反向电流、对应温度/姿态、最大速度、实际TX与Iq。至少覆盖冷态/暖态和操作者报告的阻力最大位置。已知0.4A脉冲可动只用作低能量探针背景，不能直接写成全方向Ibreak。

采用实测分布中的稳健上沿及明确余量形成初始正/负补偿，余量仍须处在批准边界内；不做“找到最低电流即停止”的优化。若同角度重复差异很大，先查机械预紧、同轴度、连接偏载，不用更复杂软件掩盖。

### 2.3 速度环增益

先固定摩擦补偿候选，在同一速度/温度/方向下调Kp，再逐步加入Ki处理剩余偏差；避免一次同时改变Kp、Ki、电流帽、速度滤波和jerk。Kp太低表现为负载变化后速度误差大；太高可放大量化/机械振动。Ki用于消除稳态偏差，不承担从零慢慢寻找全部起动力矩。

先试±3、±5°/s的恒速段（机构区间允许时），再±10，最终才到当前模式20°/s。正反每段有清晰加速、steady、减速标签。采用增益候选的有限集合，连续两次明显恶化就回上一个已测配置，不无限自动搜索。

运动方向制动留出电流余量。补偿移除时做积分接管/无扰切换。起动解决后再比较20/30/40ms RX估计窗；若能用当前估计满足目标，就不强制替换。

## 3. Pitch独立速度试验

先固定q_hold保护另一轴，pitch在远离端挡的可行区间做短恒速段，检查SpdRef实际是平滑还是被其它路径覆盖。采集type2 q/velocity/torque及异步Iqf/VBUS；所有点保留时间戳。

首轮不切模式、不改CurKp/CurKi、不超过5A。分别测试向上/向下和多个重心力矩角；不要假定pitch+一定向上，现配置注释为正方向镜头向下，必须以实际编码器/相机方向确认。

有限的起始A/B可用Kp=4不变、Ki0.02与0.05比较；必要时在现有已支持区间调Kp。这个建议只是最小实验，不宣称0.02一定更好。每次写入gain需异步读回、记录值，并确认不能造成不可承受的模式切换掉电。正常服务不切position来“增强保持”。

若诊断显示主机feedback延迟明显限制位置外环，可比较50Hz和100Hz反馈请求。判断依据是有效数据年龄/周期尾延迟和实际运动改善，不是CAN理论容量。不得把2000/500Hz目标数值写进报告称已达到。

## 4. 位置外环与运动整形

局部速度环先通过再做位置测试。可复用当前`response_probe`/reference manager，但先核实命令语法和允许幅度，不能把“响应omega”误当速度环Kp。

建议正负0.5°、1°、5°，起动位置不同、两方向至少各5次；profile阶跃不是向机构注入无限速度的数学阶跃。分别测命令到移动、10–90%响应、峰值过冲、稳定时间和最终误差。

目标保持3s后反转；再做低频三角/平滑扫描。先用相同上层v/a/j比较环路改动，最后才逐步提高上层需求。保持position/velocity增益分离，避免“缩短jerk斜坡”被报告成“反馈延迟改善”。

当目标速度等于actuator最大速度时，测落后恢复能力；不能无限积累远端目标再在停目标时突然追赶。按已合格最大能力为参考留出余量。

## 5. 归零专门验证

先把用户观察的时间点与轴/phase对应：仅pitch机械归零；yaw在此期间可能是会话基准/保持/ready运动，不能假设yaw也碰端挡。

复核coarse5°/s、fine3°/s、backoff5°等有效值，不从旧文件照搬接触努力阈值。记录每个contact candidate为什么成立、期间位移、运动恢复、effort方向/积分/限流。

先做中段摩擦平台试验，证明不会被误当端点，再进行有监督真实归零。建议至少3次完整重复，最后一次从不同起点；记录各端点重复性，暂以现有0.5°目标为基线。检查退让实际距离、接触卸载、模式切换期间的负载漂移，不能只看最终READY。

`motion_checks_abort=false`不应阻碍记录真实违规；先区分噪声误报/真实异常，再逐项确认哪些门控可恢复，不是一口气全打开或全部删除。若接触损伤/几何越界风险可见，应立即受控停止，不因用户希望少Fault而继续推。

## 6. 温升、电源、双轴与耐久

在已确认温度测量和批准电流范围内逐级试验。涵盖最不利pitch静止支撑、yaw低速反复起停、连续扫描、制动回馈及双轴同时运动。加上正常相机/AI负载检查Pi供电/调度，但不改视觉控制策略。

最少记录环境/电机温度、温升斜率、有效Iq RMS、峰值/占空、母线最低/最高、CAN错误增量、控制周期p95/p99、饱和比。至少30分钟观察为起点，未到平衡则继续或降低试验等级，不能到时即PASS。建议最后两个10分钟窗口<0.1°C/min并有温度裕量；它是热稳定判据候选，不授权突破厂商/机构限制。

新电流上限一旦合格，可以开放给控制器使用，不因节能再人为缩小。若最大合格电流仍无法完成要求，报告机构/电机能力缺口或降低参考运动要求；不能只放宽故障阈值。

## 7. 建议验收目标与量化定义

所有目标需先确认现场测量可分辨；源代码数字不等于已验收。旧payload曲线不是本次基线。

| 项目 | 初始目标/记录要求 |
|---|---|
| 输出一致性 | 普通200Hz控制中无guard竞争零流；emergency接管后旧命令不能再写 |
| 起动 | 在已合格电流下≥5°/s请求，电流/命令生效到实际位移确认p95<=200ms；同时报告原始移动和确认算法延迟 |
| 低速平滑 | 3/5/10°/s稳态段，不含加减速；窗口平均速度RMS误差<=max(0.5°/s,参考10%)；无反复停滞-窜动 |
| 位置 | 0.5/1/5°两方向测量；稳态误差<=0.15°；过冲<=max(0.15°,步幅10%)；先报告实际稳定时间，再以<=1s作为小幅运动目标 |
| 反向/保持 | 正反均能恢复，保持目标固定；连续静止2s漂移<=0.15°，没有积分清零导致下沉 |
| 归零 | 中途摩擦不误报端挡；重复性不劣于现有0.5°目标；无未解释的模式切换漂移 |
| 反馈 | 记录两轴真实RX率和p99年龄；建议yaw p99<10ms，pitch初始<30ms、100Hz试验<20ms；不得把200Hz日志独立样本率当yaw CAN帧率 |
| 保护 | 短时可恢复问题不误掉电；真实失控/急停可停止；保持电流与禁能结论分别有证据 |
| 热/电气 | 覆盖代表性工况，传感器有效，未超批准边界；没有温度数据时热资格NOT_RUN，不写PASS |

## 8. 结束与回滚

每次结束保存实际参数/寄存器读回和trace，按launcher受控停止或恢复已批准服务。回滚是回到**已验证的current-mode配置**，不是只把YAML改回voltage；电调Current Ring仍开时裸0x1FF可能不工作。[R01]

失败报告写“哪一项、哪一工况、什么观测、恢复到哪个配置”，不要只写“PID不好”。一次测试失败不等于必须重写整个架构。
