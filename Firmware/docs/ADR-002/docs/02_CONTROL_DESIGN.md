# 02 · 控制设计与最小数据契约

除明确标注的当前值外，本文件为ADR-002提出的实施方案。公式中的量均在统一输出轴坐标下，以rad/s/A为主；UI可以显示度。不要把CyberGear内部增益的数值与host SI增益直接等同。

## 1. 分层、分轴，而不是再套一层万能PID

共同位置外环保留 `v_des = v_ff + Kp_pos * limited(q_ref-q)`，再执行能力/边界约束。外环不新增积分；大误差通过现有轨迹管理追赶，不把长期误差变成无限累积的速度目标。

Yaw：host速度PI输出A，GM内置电流环执行。Pitch：host位置P输出速度，驱动RunMode=2闭合速度/电流；默认不在主机叠速度PI。当前host200Hz保留；两轴参数独立。

规划参考与执行能力分开：`reference_target <= actuator_maximum <= qualified_axis_limit`。跟踪需要正向追赶余量，但不能通过抬高尚未验证的actuator最大值制造余量。先在现有批准能力内减少参考目标，或证明更高能力后提升actuator cap。给定模式速度达到上限而仍落后时标记饱和/能力不足，不继续无意义调大Kp。

## 2. Yaw速度估计

### 数据路径

CAN callback保留原始`rx_ns / seq / encoder_raw / unwrapped_q`；控制周期获得一致快照。估计只消费**新样本**，重复读取不生成零速度，不能把同一个位置按不同now当作多个独立测量。unwrap跨8191→0连续；重启/generation变更清掉历史。导出的原始rx时间不能为了避免race被静默改写；出现轻微“晚于cycle_start”的帧，记录真实时间并用快照取得后的now算age。

先实现一个有界RX时间窗的斜率估计，可用最小二乘：
`v_hat = Σ[(t-t̄)(q-q̄)] / Σ[(t-t̄)^2]`。

建议离线A/B候选窗20/30/40ms；这是试验范围，不是保证适合该轴。可以在1kHz callback侧维护小型固定环，200Hz读出，无文件I/O。先比较静止噪声、低速量化、加速相位延迟，再选窗。不要同时保留多层低通然后仅用最后的光滑曲线声称运动已经顺滑。当前50ms PI滤波作为基线；判稳100ms估计可暂保留，但日志名称必须区分。

控制器dt用于积分；RX dt用于观测。一个周期无新帧且反馈仍在有效期内时不重新差分；按同一估计进行有限控制。超过既有反馈失效边界，不能继续当健康闭环。单次迟到>20ms但反馈新鲜时：冻结本周期积分、重建参考与计时，执行有界输出/制动；不把时间迟到与不可恢复的参数NaN混为一类。

## 3. Yaw电流控制

定义速度误差 `e_v = v_des - v_hat`。

```text
u_pi  = Kp_v * e_v + I
u_ff  = friction(direction, movement_state) + k_acc * a_ref   # k_acc默认关闭
u_req = u_pi + u_ff
u_applied = final_current_and_slew_limits(u_req, thermal/duty/mechanical authority)
I_next = bound(I + Ki_v*e_v*dt + Kaw*(u_applied-u_req)*dt)
```

Kp单位 A/(rad/s)=A·s/rad；Ki单位A/rad（因为积分的是速度误差×秒）；Kaw单位1/s。现字段`current_ki_a_per_rad_s`命名不准确，可保留兼容别名、明确真实单位，不用大规模改名破坏配置。电压gain不能除一个常数得到电流gain。

**最终抗饱和**必须看到摩擦前馈、breakaway、限电流、限电流斜率、边界/热降额后的实际输出。只看PI自己的clamp会漏掉其余限制。若TX失败，`u_applied`不能冒充“已经施加”：区分requested、limited、last_successful_tx及反馈Iq；丢TX时冻结/追踪上次实际命令并交健康策略处理，不把未发出的电流积分进去。

开启/关闭补偿或切换参数时应实现无扰切换：`I_new = clamp(u_previous - Kp_new*e_v - u_ff_new)`。条件：previous来自可信已发出输出、参考没有危险跳变。短暂停、quiet deadband不自动把I清零；保持负载需要的电流仍可由速度环输出。长时间静止下不维持多余起动boost。

### 3.1 最小摩擦补偿状态

只使用`STATIONARY / BREAKAWAY / MOVING`，另外记录方向与反向待完成；它是轴内控制状态，不新增顶层业务模式。

| 状态 | 进入条件 | 输出与退出 |
|---|---|---|
| STATIONARY | 已停止或正常位置保持 | 无移动意图时不加breakaway；保留必要闭环支撑电流 |
| BREAKAWAY | 有有效移动意图，未越界，反馈/电流资格有效，轴实际未动 | 有界斜率上升到该方向实测起动补偿；运动确认后退出；超时停止加码 |
| MOVING | 位移和速度持续证明确已运动 | 平滑过渡到该方向动摩擦补偿，PI修正残差 |

运动确认使用高于静止量化/噪声的**累计位移+连续时间**，不要只用一帧rpm。对GM初始可试3个编码器计数和20–50ms证据窗，但最终阈值由噪声、低速和响应目标共同决定；日志保留确认延迟，不能拿迟确认伪装真实电机起动慢。

补偿按**所需运动方向**选择，不直接用带噪的测量速度sign。反转时先完成有界制动，接近零速后再切补偿方向。方向迟滞避免零附近来回切换。持续反转轨迹不能每个控制周期重新生成一次breakaway事件。

第一次实现仅需正/负起动电流与正/负运行电流。按角度变化的摩擦先诊断机械装配；不要马上做整圈查表。若确有可重复角度依赖，再加小型角度表；yaw会话零点不保证物理零点，不能把上一会话角度表直接套在新的相对坐标。

### 3.2 起动失败的处理

使用受批准的峰值、最长起动时间、最大位移/速度、温度和电源条件，完成**一次**可解释的起动尝试。计数绑定intent generation和实际尝试完成，不绑定loop tick。持续不动时不无休止“敲击轴承”，也不开始放大远端q_ref误差。

若仍可控制，停止推进不可实现的参考，保持受限闭环支撑，报告`motion_limited / breakaway_exhausted`；保留原操作模式，允许新的可行方向/命令恢复。这个结果不是普通噪声触发的HOLD，也不是机械仍被卡住却声称“能正常继续”。真正失控风险按第5节处理。

## 4. Pitch控制与归零

### 4.1 服务运动

保持RunMode=2。SpdRef由单一主机外环发出，LimitCur=5A为现有机构约束。实际持流只由电调误差决定；“允许5A”不等于“强制持续5A”。优先整定内部SpdKp/SpdKi，不改内部CurKp/CurKi。

速度环整定要暂时将复杂位置/视觉目标从实验中隔离：使用有界恒速段，另一轴主动保持；同一次实验只改变一个参数。固件1.2.1.5的增益读写/单位按当前寄存器验证。初始可在现有支持区间Kp1–5、Ki0.002–0.05内选择候选，不默认超过源码范围；这些范围只是当前调试代码接受的区间，不是厂商绝对稳定性证明。候选起点可采用Kp=4固定，比较Ki=0.02与0.05；是否需要降低/提高由Iq与运动相位决定，不先声称0.05一定过大。

持续恒速而主机参考平坦、Iq缓慢升高→突然解锁→Iq尚高/速度冲出，支持stick-slip/积分残留假设；连续运动中Iq和速度规则正弦振荡且修改gain改变振荡频率/幅度，支持环路整定假设；波动随机械角而非时间重复，优先检查轴承安装/预紧/双支撑同轴度。三类可以并存。

诊断读Iqf/VBUS用非阻塞低频读取，按自身RX时间打点，不冒充每200Hz都有新电流。先用10–20Hz附加寄存器诊断，只有带宽足够且需要时才提高；状态反馈目标可试100Hz（10ms）代替静态50Hz，必须比较实际p99 age、TX/RX、周期尾延迟。保留原50Hz作为A/B，不盲改所谓`echoFreHz=500/1000`，串口/存储表不等于当前CAN协议配置。

### 4.2 保持与停车

服务暂停：固定q_hold于进入瞬间，通过原速度模式闭环支撑；不要每周期把q_hold更新成实际q，否则漂移被吞掉。归零/parking已有受控模式不得无条件切换。`v_ref=0`时内环可输出非零电流制动/支撑；`iq_ref=0`则没有同样保证。

### 4.3 归零

分开记录：coarse approach、contact candidate、contact dwell、backoff、fine approach、settle、ready move、yaw session reference。归零低速与服务20°/s必须使用分开的整定/验收。

不把普通摩擦平台一律判成端挡。已有位置进展、effort方向、motion history和重复性判据要保留并重测；`effort_hard_contact`这种无运动历史捷径在高静摩擦新机构上必须单独验证。起动补偿期间需明确判据状态，但不能屏蔽真正大力矩/端点危险。接触后先卸载接触推力，再按现有验证过的方式退让。

第一版保留speed接近、position退让，定位症状后再决定是否做同speed模式退让。正式放弃mode-switch必须证明残余积分、反向、负载支撑和端点重复性均不劣化。禁止为了消抖删除端点限幅、盲目加大dwell或超过5A。

### 4.4 有条件的电流模式替代

只有原生速度环限制已被数据证明且上述修复不足时，新增独立实验RunMode=3；原服务speed继续作为回滚。优先简单current而不是一次加入MIT刚度/阻尼/扭矩全套参数。

需要新增模式支持、Iq命令限幅<=5A、健康/enable序列、反馈节奏、pitch重力支撑、失联行为及有载停车验证。资料中的LimitCur仅明确用于speed/position，不能沿用旧读回就宣布current/MIT也硬限5A。若无法建立该模式下可信约束，不晋升为生产模式。本ADR核心PR不依赖此实验。

## 5. “继续运行优先”的单一输出仲裁

业务模式（MANUAL/AUTO_TRACK/AUTO_ROAM等）与输出处理（正常/受限/制动/禁止输出）是两回事；复用现有类型实现，不要求新建全局状态机框架。

不要全局删除所有名字带Hold的分支：既有`Phase::Hold`、`GuardResponse::Hold`和操作者的Hold请求不等价；某些调试/服务命令本来就在Phase::Hold内执行。按实际reference、operational mode和最终输出判断是否被无故停止，不按枚举名字做替换。[S06,S08,S16]

| 证据 | 动作 | 明确禁止 |
|---|---|---|
| 可恢复摩擦、短暂饱和、正常换向 | 保持模式，正常闭环/有界补偿，记录性能事件 | guard独立穿插零电流 |
| 一次历史CAN错误，当前通信正常 | 记增量、确认恢复，继续运行 | 累计counter非零永久故障 |
| 一次迟到但反馈新鲜 | 冻结积分、重建计时，受限闭环 | 默认deenergize_all |
| 能力不足但轴仍可控 | 停止推进不可行参考，主动制动/支撑，允许可行命令恢复 | 反复满流撞击；假称已跟上 |
| 反馈过期、持续无法发送、控制心跳停止 | 取消普通运动授权；按已验证能力停止，无法闭环时明确状态未知 | 用旧值无限持流并称闭环 |
| 真实驱动异常、热/电压危险、不可制动越界 | 立即按风险阻止危险输出；必要时禁能/硬件保护 | 等到thermal runaway或损坏发生才停 |
| 用户明确急停/停止 | 按语义立即执行既有受控停/急停协议 | 被“keep running”策略吞掉 |

实现要求：普通输出每轴每周期最多一个最终决定。guard紧急接管设置epoch/token，使已经排队的旧普通命令失效。若某轴失效，不能因此无条件释放仍健康且承重的pitch；平台需要双轴停止时，健康轴先保持/受控停车。若pitch本身不安全继续输出，则不能为了防下落坚持通电，需依赖已有机械防护/人工支撑。

不要在FAULT日志里宣称物理掉电，除非真有断电执行与证据；GM零电流帧没有disable状态回报。

## 6. 电流与热资格

三层边界分开：协议可表示范围、设备/机构禁止越过的上限、当前载荷/散热/工况已合格上限。第一批实现不解除现有硬边界；修正`1.62A恒等所有工况持续安全`的注释和资格逻辑。

热平衡需要有效温度及代表性负载，不是空转/空闲温度不升。建议记录温度斜率、环境、静止保持/低速重复起停/最高合格速度/双轴工作、Iq RMS、占空、冷却方式和24V母线。建议30分钟只是最低观测起点；最后连续两个10分钟窗斜率绝对值<0.1°C/min且温度/母线均有批准裕量，才是可讨论平衡的证据，不能替代厂商热边界或温度传感器校验。

GM温度raw尚无已验证°C缩放，raw ceiling=0意味着当前host温度门控关闭，不意味着不需要热保护。先建立温度测量/映射或使用合适外部测量，并记录外壳/绕组测温差异；不要拿125°C绕组最大值直接设为允许外壳温度。pitch保留当前温度保护。

最大允许电流可以开放给控制器，但不强制恒流；瞬时起动和持续静止需要分开资格。遇热裕量减少，优先降低运动需求并保留制动/支撑能力；若剩余电流连安全保持都不够，必须采取安全停机/支撑，不能无限“降额继续”。滑环5A是导体/DC路径约束，不能直接等同电机q轴电流；制动回馈还需检查电源吸收能力与母线过压。

## 7. 最小遥测契约

复用现有高频窗口/trace，不让网页15Hz成为调试依据。每轴每控制周期记录：

`cycle_ns, rx_ns, rx_seq, command_seq, axis, phase, operational_mode, actual_drive_mode, q_ref, v_ff, v_after_position, v_after_limits, a_ref, q, v_raw, v_est, estimator_id, Kp, Ki, integral, friction_state, ff_current, current_request, current_limited, last_successful_tx_current, iq_raw/iq_A+valid, current_cap, clamp_reason, guard_action, intent_generation`。

低频附加温度/电源字段有各自时间戳和valid。pitch速度模式的host current command为null，不填0；其真实可执行命令是SpdRef。模式字段区分CyberGear type2使能state=2与RunMode寄存器=2。

日志有界非阻塞；丢日志计数可见。不能由于磁盘慢/新遥测导致控制线程丢周期。离线CSV工具只实现上述契约的一个最小统计子集，不是native ABI。
