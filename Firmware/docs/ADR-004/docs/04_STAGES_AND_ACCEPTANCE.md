# 04 · 阶段、工况、自动验证与交付

## 1. 阶段边界

### 阶段 1：完全离线

定义/实现重力变换、水平面、分类、连续 IK/路径映射、单一相位时间律、留距算法、reticle投影、接口/参数及失败分支。复用同一 C++数学/控制核心在独立宿主与production的构建方式，不用Python重新实现一个最终控制器。

阶段1用参数化/合成硬件完成所有软件分支测试。缺IMU标定、未知限位/时延/制动能力只表现为待注入参数，不阻塞数学软件实现。合成物理值不得晋升为实际profile。本包的Python小参考只验证局部几何，不能替代完整阶段1交付。

### 阶段 2：测量后自动注入，优先复用

依次核对现有 R_PS、R_PC、相机/display映射、关节历史/零点、时间映射、当前姿态的停止/负载资格。能复用不重测；缺失只运行既有标定/辨识方法的必要部分。

新测量主要是：准静止 gravity window、跨关节姿态的不变性、实际数据延迟/散布、独立水平参考的系统偏差、当前姿态下profile适用性。记录未经融合的原始证据与来源。用程序计算/更新 GravityFrame 与相关适用性，不手选PID、不在代码中改IMU符号试错。

控制模型若不覆盖新重力方向，交 ADR-002.2 已有自动重估流程，保留raw/安装/代码，生成新参数快照并接受其相关验证。不得将此改写为重做整个002.2。

### 阶段 3a / 3b：都必须实机

3a 在已存在的独立验证宿主，链接同一 gravity_geometry、路径/参考核心、ADR-002.2伺服和相同参数。验证真实相机/IMU/电机，不把合成输出标为实际。

3b 用真实 production executable，走实际模式、AUTO_ROAM、ReferenceManager、唯一轨迹、伺服、backend及web/HUD。包含真实预览/检测负载、scan↔track/manual、重启/归零/停止的相关回归。3a证书必须与3b参数、几何、限位、profile、姿态工况一致。

## 2. 数值目标与证据等级

以下是**本 ADR 的起始工程验收要求，不是已经测得的设备能力或厂商精度承诺**。若已批准摄影规范更严格则使用更严格者。阶段2测量达不到时如实失败/测量受限，不让agent根据失败结果自动放宽。

| 指标 | 冻结要求/方法 |
|---|---|
| 合成几何 | 水平 `abs(up·ray)<1e-9`，FK/IK ray角误差≤1e-7 rad；单位向量/正交性及分支连续自动检查 |
| 实际水平视轴 | 规定扫描、正常减速/反向期间 elevation误差 RMS≤1°、绝对峰值≤2°；入口尚未LEVEL_ACTIVE不混入，但单列入口误差/时间 |
| 实际安全距离 | 两轴在正常扫描/换向中均不进入批准 soft limit 的额外保留区；默认新增≥2°或更严格既有值；完整停止轨迹满足动态包络 |
| 工作资格 | 实际参考到达了请求轨迹/声明收窄轨迹，非靠不动取得低误差；报告实际方位覆盖、速度和限制原因 |
| gravity准确性 | 独立真值与传播不确定性足以支撑上方1°/2°要求；静止散布小不等于无偏 |
| reticle几何 | 与同一姿态投影真值的方向误差≤1°，共线/中心不动/缺口不变；相机向竖直时正确隐藏而非错误通过 |
| reticle实时性 | cue姿态/消息≤200ms否则隐藏；记录控制姿态、显示状态、视频之间各自延迟，不将几何指标冒充逐帧曝光对齐 |
| 正倒置 | 已知姿态分类100%正确，近侧置按滞回；分类不会改变电机或图像标定符号 |
| 复用 | 相同参数/变换热加载不改变二进制；重摆基座不无故擦除机械零点/传感器安装标定 |

真值不可只使用同一个BNO085自证。使用独立校平的光学参考/外部角度测量（例如已测空间方位/仰角的标靶阵列），将误差换算到光轴仰角。仅看画面一条横线平不平只能验证 roll，不能单独证明 optical axis elevation=0。测量不确定性需≤对应验收误差的1/3，否则 MEASUREMENT_LIMITED。不得把滤过的IMU输出当独立真值。

每个必需正向物理工况默认3个完整往返；报告每次RMS、全程峰值和最小留距，不称为统计p95可靠性证明。正置、两种方向的倾斜、复合倾斜、倒置及倒置带倾斜都要包含；角度值由批准安装包络与实物夹具范围注入，不编造已完成20°/45°实验。

没有可调物理倾斜/倒置支撑条件时，相应实机状态为 NOT_RUN/BLOCKED，不以数学通过替代。条件缺失不阻止阶段1。

## 3. 固定场景矩阵

S01 正置水平的基线平扫（3a+3b）。
S02 正置前后倾与左右倾：正负方向（3a+3b）。
S03 复合倾斜，yaw/pitch明显同时运动（3a+3b）。
S04 倒置及倒置带倾斜，世界方位方向正确（3a+3b）。
S05 侧置/近奇异域：在可达区正向通过，不可达域明确截断（软件全覆盖，3a+3b安全可行部分）。
S06 起始相机不水平，受控进入水平路径；新路径不可达时不启动（3a+3b）。
S07 pitch先限制扫描范围；两轴整段留距与端点换向（3a+3b）。
S08 内部极值/不连通可达段，端点合法但中途不合法的反例（软件必需；实机仅批准可执行路径）。
S09 yaw跨±π连续、物理unbounded与有界政策区间（软件全覆盖，3a+3b本机实际接口）。
S10 高路径曲率或pitch速度受限时双轴同步降速，q/v/a一致（3a+3b）。
S11 scan↔track/manual和stop：无参考冲突、无异常突跳、停止留距有效（3a+3b）。
S12 扫描动态加速度不变成base tilt；搬动后停稳重新获得重力（软件注入+3a/3b有监督搬动/停稳验证，不要求带电强行翻转机构）。
S13 IMU过期/乱序/generation变化、host tare存在：不假水平、不取消硬保护（软件故障注入；3a+3b可控断流/恢复）。
S14 HUD正倒置、rotate180/镜像、fx≠fy、crop/letterbox；共线/固定中心（软件所有映射；3a+3b当前真实camera/display）。
S15 相机望向竖直、无效gravity、stale UI正确隐藏；control pose与video年龄分账（软件+3a/3b真实可达显示）。
S16 重力方向改变引起profile适用性检查；旧资产复用、必要参数更新不重编译（3a+3b，覆盖当前批准安装工况）。

表中不存在的物理接口不需换硬件制造，但对应数学/接口分支必须用合成测试覆盖。倾斜与倒置正向物理能力不可省略。所有负例“拒绝得正确”不替代S02–S04成功扫描。

## 4. 有界实施与诊断

W1：共用数学与接口；W2：采集适配/重力状态/asset适用性；W3：一条联动路径和留距；W4：现有reticle接线和双验收。每项范围见00启动指令，不加入双摄、ReID、自动快门、通用校准数据库、360°全向规划或持续移动底座。

失败归属固定：水平几何错误→查frames/time/IK；reference水平而actual不水平→查002.2执行/当前姿态模型资格；独立通过生产失败→查reference来源、二次限幅/整形、版本和调度；只有图形错误→查display transform/time/reticle，不改电机gain。

每个故障必须产出最小反例/失败不等式、原始trace与输入身份。优先复用已保存数据离线定位；软件问题修正后对受影响项回归，不因发现一项问题重新全量采集/重调。
