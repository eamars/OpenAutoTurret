# 02 · 双轴平扫、连续可达区间与安全留距

## 1. 入口和所有权

在既有 AUTO_ROAM/scan 请求增加 `reference_frame=GRAVITY_LEVEL`。保留旧 JOINT 路径的语义与资格，不默认把旧 `roam_pitch_deg` 当重力仰角。重力扫描失效时不得静默退为联合空间扫并继续显示“水平”。

`ReferenceManager` 仍只负责来源/几何；ADR-003 已接受的唯一轨迹 owner 扩展一个 `LevelSweepPath`。两轴 q/v/a 由它产生，ADR-002.2 控制核心执行。现有 mode transition、目标捕获、stop/park、输出互斥继续复用。水平面约束只用于该 scan，不能强加到 ADR-003 的任意目标跟踪。

基座必须在扫描期间固定。启动从当前有效 optical ray 的水平投影确定默认中心方位；投影近零时使用该 gravity_epoch 的 e1。请求 span 延用已配置搜索幅度的**大小**作为初始请求，不将旧关节绝对 endpoints 重命名为世界方位。旧命名关节区间仍是附加政策约束；新增 gravity endpoints 必须带显式 frame。

## 2. 复用实际逆解而不是小角度补偿

将 d_B 转换成已有 base LOS，交给实际外参的 LosJointSolver。每个解核查：forward kinematics 光轴误差、physical/unwrapped 关节区间、branch 连续性、相邻速度方向。

固定一个连续分支 q=f(φ)。不能独立选择每个采样点的最短角，更不能把 wrap 到 [-π,π] 的值直接发给连续机械轴。yaw 无机械边界时可以 unbounded，但请求 scan 仍有自己的方位端点；unknown/unestablished limits 不等于 unbounded。[S06,S07,S08]

用现有 FK/IK 的导数得到 f′、f″、f‴（复用FK/IK的解析导数，有限差分只作离线交叉验证，不引入自动微分框架）；在 Jacobian 退化或 branch 终止前截断有效域。不能在 pole 附近硬除以接近零的 cos(pitch)。

### 连续区间判定

交集为：请求方位段 ∩ 实际行程/政策区间 ∩ 工作保留区 ∩ 同一 IK 分支 ∩ 动态能力 ∩ 模型适用域。**内点也必须验证。**

采用单参数路径的确定性区间检查，不建设通用路径规划器：以请求端点及 IK 分支边界分段；对软界限距离及导数奇异判据求边界/驻点，使用带导数界的二分细化。已知上下界不能证明整段合格时继续细分；达到 1e-5 rad 的相位分辨率仍无法证明则保守排除该小段，记录边界原因。禁止只用稀疏点测试后宣称严格整段安全。这里要求的是本二轴几何的一维工程保守界，不是形式化证明平台：禁止为此引入通用区间算术/可达集/运动规划框架。单次路径构建最多2048个区间节点，超过则明确收窄/拒绝不能判定的段；路径构建在非实时准备阶段完成，控制tick只读已接受路径并做现有动态监督。

优先取包含当前投影的可行连通段；否则取可经既有受限入口轨迹抵达的最近段，按进入代价、绝对方位、branch ID 固定打破平局。不跨不可达间隙瞬跳。入口转向不算已进入水平扫描；到位/方向合格后才标 LEVEL_ACTIVE。无足够往返/制动空间则 `NO_FEASIBLE_ARC`，保持既有受控支撑，不自动增大范围。

## 3. 同一时间律保持水平路径

同一相位 φ(t) 产生：

`q=f(φ)`

`qdot=f′(φ)*φdot`

`qddot=f″(φ)*φdot² + f′(φ)*φddot`

`qjerk=f‴(φ)*φdot³ + 3f″(φ)*φdot*φddot + f′(φ)*φjerk`。

将两轴速度/加速度/jerk约束折算到同一时间律。导数为零的轴按该处真实不等式处理，不机械除以零；高曲率/near singularity 同步降速或截短路径。不能分别对 yaw/pitch 低通或各自限幅后再声称 f 关系成立。

复用既有受限参考状态/积分器，增加这个路径映射；不是新建另一份最终参考。若现有逐轴积分器不支持曲线路径，就在**同一 owner**内实现该一种标量路径时间律，并保留其他轨迹类型不变。用离散状态与导数一致性测试验证 q/v/a，不能只在遥测时差分凑 a_ref。

正常到端点前，利用同一时间律提前减速，φdot/φddot按已有 jerk 约束到允许反向状态后再换向；不要每圈强制停很久或变成阶跃往返。正常减速和反向也须保持水平误差指标。真正硬保护可以优先安全停车、暂时离开水平路径，但立即撤销 LEVEL_ACTIVE 并保存原因。

## 4. 留距：不是加一个固定角度就结束

所有边界以**实际运行时编码器坐标**为准，IMU 不建立/覆盖机械端点。

现有 hard→soft 内缩保留。本包新增工作保留距离 `extra_clearance` 的设计默认值为每个有界轴 **2°**，或现有更严格的工作留距（取较大者）。这不是实测安全证书、不是替换原有例如 5° 的 soft margin。额外留距可通过运行时配置加大，不能由自动求解器减小至小于批准值。

定义 extra reserve `m_j=max(批准额外留距,既有额外留距,尚未覆盖的执行/映射误差界)`。每一项明确列账，禁止把已经计入 soft limit 的误差/留距再次暗中叠加；也不能把未计入的误差当成已覆盖。

当前测量 q,v,a 及最大实际执行滞后共同输入已有安全制动能力，得到在停止过程中的有向最大位移 `Δq_stop^- / Δq_stop^+`。每一控制点必须满足：

`q + Δq_stop^- >= q_soft_min + m_j`

`q + Δq_stop^+ <= q_soft_max - m_j`。

停止可达范围必须覆盖当前加速度、jerk 受限制动、延迟、模型/执行误差；不能仅使用 v²/(2a)。公开 safety_envelope 的 speed-only 辅助式不自动构成完整证明；若当前已完成 ADR-002.2 已有合格停止接口直接复用，否则只在**该既有接口**补足必要状态，不建设另一套安全监督。[S07]

规划器检查相位停止路径的全程极值，两轴物理监督独立检查实际状态的停止可达范围。正常反向必须留在保留区；异常也以不越原安全边界为优先。零速时仍有工作留距，不能把速度归零当成允许贴边。

动态空间不足时：同步减速 → 缩短可行弧 → 原路径受控停止/换向。无可行停止条件则交既有安全链，不以继续平扫为由冒险。只有当前姿态合格的减速能力可用于证明，不能用竖直空载时能力代替倒置承重时的制动。

## 5. 安装姿态对已有动力学资产的影响

重力力矩的一般关系用于解释适用性，不是新增手填电流项：

`tau_g,j = axis_j_B · [(r_com_B-r_axis_j_B) × (m*g_B)]`。

倾斜后 nominal yaw 轴可能不再与重力平行，所以它也可能承受重力偏置。倒置可反转 pitch 的支撑需求。不能沿用“yaw永远无重力”作为新工况约束。

优先由已接受的 ADR-002.2 模型读取 up_B/安装工况；若其 h 表未覆盖该方向，调用其**现有**自动辨识/计算程序取得必要局部数据。只扩展 operating_point 身份和适用性判断，不在 ADR-004 中重新设计摩擦模型或自动调参器。适用域外输出 `PLANT_SCOPE_MISMATCH`，阶段 1 仍可完成，相关实机扫描等待当前姿态资格。

相同硬件再摆放不清除编码器机械零或安装矩阵；需要新 gravity_epoch/动力学工况证据。安全停车、正常归零和 mode 交接在正置/倾斜/倒置的必要工况做回归；不因需要回归就重写归零。
