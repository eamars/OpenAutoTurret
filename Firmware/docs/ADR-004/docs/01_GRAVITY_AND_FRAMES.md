# 01 · 重力、坐标与安装方向

以下为 ADR-004 的数学决定，非本机测量值。运行时统一 rad、s、m/s²。R_XY 将 Y 坐标中的向量转换到 X；所有旋转是正交、det=+1，不能用反射矩阵代替安装旋转。

## 1. 坐标

B：机械基座，+X 前、+Y 左、+Z 名义上方（并非必然重力向上）。P：pitch/payload；S：IMU；C：相机，+X 右、+Y 下、+Z 光轴；N：适配到 z-up 的 raw game quaternion 导航参考。[S05]

复用已校验的关节方向/零点，理想序列写为：

`R_BP(q)=Rz(q_yaw) Ry(q_pitch)`

`R_BS=R_BP R_PS`；`R_BC=R_BP R_PC`。

真实 R_PS/R_PC 从已有标定资产注入。公开源码的 nominal R_PC 可用于合成测试，不能覆盖已有实际标定。几何约定中的正 pitch 对 nominal 相机是向下，用户显示单位不改变该符号。

## 2. 从活动 IMU 得到基座重力

`R_NS` 是经一次适配确认方向的**原始** game quaternion：

`up_S = transpose(R_NS) * [0,0,1]`

`up_B(t_s) = normalize(R_BP(q(t_s)) * R_PS * up_S(t_s))`

`down_B = -up_B`；需要带量纲向量时 `g_B = -g_local * up_B`。

本功能主要依赖方向。g_local 可由有效准静止数据估计；9.80665 m/s² 只能标为标准重力参考常量，不能冒称本地实测值。

IMU quaternion 的 XYZW 顺序、主动/被动方向、厂商导航轴约定必须由适配层和已知姿态回归锁定；不允许 agent 在实机上轮流试取逆/反号。先用已有标定及离线几何排除错误，再做有依据的静态确认。[V01,V02]

### 不允许的输入替代

- `relative_xyzw = q_ref^-1*q_current` 去掉了初始姿态，不可恢复启动时倾斜。[S04]
- 相机/IMU 的 roll、pitch 不是 base roll、pitch；活动轴旋转必须消去。
- 动态加速度包含运动分量；不可直接归一化后每 tick 当 gravity。
- game yaw 无磁北约束，但绕 N 的竖直旋转不改变 `R_NS^T*ez`，因此不需要校准磁北。
- 永久安装矩阵 R_PS 与会话导航参考是不同资产。host 相对 tare 改变不自动使物理安装矩阵失效；设备重置需重新确认 raw 导航及连续性，不擦除机械零点。

## 3. 对时与重力状态更新

在 t_s 插值同 generation 的**原始有效关节历史**，不使用最新 q 与旧 IMU 拼接。时间偏移及不确定性来自 ADR-002.2；传播的角误差至少考虑 `|ω|*时间不确定性`。拒绝跨重启/跨零点的插值，不把重复 log tick 算新传感器样本。

重力状态只需 `UNQUALIFIED / VALID / STALE` 三种资格，附原因码，不新增全局业务 FSM。

准静止窗口沿用已有 stationarity 证据；本包起始窗口为 2 s，至少 50 个独立 game 样本（是设计要求，不是声称当前已达），并要求 encoder/gyro/accel 有效且同窗。静止阈值优先用已接受的 ADR-002.2 数据与噪声约束，不新手调。对各样本的 up_B 做球面稳健平均：以归一化向量平均为初值，角残差 Huber 权重（阈值1.345倍角尺度）迭代至 1e-8 rad 或 20 次；角尺度用 MAD 和已有传感器误差下界的较大值，避免零噪声除零。

静态重复散布只描述精密度，不能消除安装/融合系统偏差。GravityFrame 的不确定性还要含安装和对时误差，并用独立水平真值验证。

准静止合格后发布新 gravity_epoch。`estimate_ns`记录这个canonical方向的估计时刻，`sample_ns`记录最后一个支持当前资格的有效诊断样本；二者不同。锁住方向不代表可以锁住freshness：扫描期间必须持续有新的有效IMU/关节样本。初始2 s窗口只在建立/重新建立参考时需要，不要求每次反向额外停2 s。一个扫描腿内冻结 canonical up_B 与水平基向量，动态 up_B 只用于残差/搬动诊断；不要追逐扫描加速度造成的假倾斜。leg 结束后仅在准静止且不破坏连续性时接受小更新；超过变化线则重新进入/规划，不能将正在走的路径瞬间旋转。

搬动判据采用方向残差 `angle(up_B_dynamic,up_B_locked)`，同时看活动关节已消去后的 gyro 残差和传感器质量。阈值为已批准外部水平误差界与 3 倍传播不确定性的较大值，持续窗口默认 0.5 s；明显 generation 断裂/过期则立即使资格失效。阈值和 dwell 是设计配置，非设备故障极限。不能仅依靠 `|accel|≈g` 宣称正在加速的底座仍静止。

若搬动/失效发生：不再推进重力扫描，原伺服受控制动并支撑；停稳后重新测量。缺可靠反馈时原硬件保护优先，不能为了支撑继续相信失效数据。恒定未知线加速度与倾斜不可凭单个 IMU 任意区分，因此本 ADR 明确不覆盖连续移动平台。

## 4. 水平面与方位

令 u=up_B；选择 `e1=normalize(ex-u*dot(u,ex))`。若投影长度<0.1 则选 ey 的投影。`e2=u×e1`。此选择只在 gravity_epoch 建立时做，不能逐 tick 切换导致方位跳变。向旧 epoch 对齐时使用投影后的旧 e1（有效时），保留连续方位来源。

水平面为 `u·(x-o_B)=0`。它是通过选定基座原点的**局部方向平面**，不表示地面位置、海拔或真实可見地平线距离。

水平视轴：

`d_B(φ)=cos(φ)e1 + sin(φ)e2`，所以 `u·d_B=0`。

显式等仰角扩展仅复用同式：

`d_B(φ,β)=cos(β)[cos(φ)e1+sin(φ)e2]+sin(β)u`。

默认 β=0；β≠0 时遥测名称为 CONSTANT_ELEVATION，而非 LEVEL。重力方位是本地参考，不标“北/东”或绝对罗盘方向。

## 5. 正置与倒置

`c=dot(up_B, nominal_base_z)`；安装倾角 `tilt=acos(clamp(c,-1,1))`。

设计滞回：非明确状态需 c>sin(7°) 进入 UPRIGHT，c<-sin(7°) 进入 INVERTED；保持当前明确状态直到跨越 sin(3°) 或 -sin(3°)；其间为 SIDEWAYS。无可信 gravity 为 UNKNOWN。初始 nominal 阈值 5° 配合 2° 滞回，数值只分类显示，**不决定是否能扫**。

几何计算一直用完整向量，不按布尔标记将 pitch=-pitch/yaw=-yaw。正倒置重装通常只改变 base 相对重力，不改变 R_PS/R_PC；若传感器/相机被独立拆装才按资产规则重标定。
