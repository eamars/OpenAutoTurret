# ADR-004 · 重力参考平扫与水平取景指示

**2026-10-02 · 相机云台 · 一个完整交付范围**

用户已确认 ADR-002.2、ADR-003 完成。本包以其有效控制核心、独立验证宿主、标定与生产链为依赖，不重新开发这两项。本次交付为**开发计划与离线几何参考**，不是已集成、部署或通过实机验收的固件。

## 必须实现的六件事

1. 以 ADR-004 归档并实施；2. 判断重力方向；3. 建立局部水平面；4. 双轴联动平扫且保留限位安全距离；5. 区分正置、倒置及侧置/未知；6. 让现有 reticle 的两段共线横线正确指示水平倾斜。

这里“平扫”默认指**相机视轴保持与重力垂直，扫描重力水平面中的方位**，不是固定机械 pitch 后只动 yaw。两自由度可控制视轴方向，但不能同时独立消除画面 roll；reticle 是指示，不是第三个执行轴。有限关节行程也不保证任意倾斜下均可扫满 360°。

## 最小完整架构

现有 IMU → 共用 `gravity_geometry` 数学模块/既有控制线程内状态 → 现有漫游/唯一参考生成器的重力平扫路径 → ADR-002.2 伺服。

同一重力状态经既有遥测 → 现有 HUD 横线。**不新增 daemon、I2C 所有者、电机 PID、融合滤波平台或视频稳定模块。**
