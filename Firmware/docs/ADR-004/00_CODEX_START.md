# ADR-004 · Codex 执行合同

任务：让已完成 ADR-002.2/003 的**相机云台**在固定但倾斜/倒置的安装姿态下，按重力水平面平扫，保留限位余量，并将同一重力参考接到现有 reticle。

## 不可自行改变的决定

1. 只有一个完整交付：阶段 1 纯数学与合成测试；阶段 2 实测参数自动注入；阶段 3a 独立验证程序、3b production 双实机验收。不得以缺少实机数据阻塞阶段 1，不得交付模拟通过而省略实机。
2. 只扩展重力几何、现有漫游/参考路径、必要遥测和现有 HUD。复用 ADR-002.2 的控制、标定、限位/制动和辨识；复用 ADR-003 的参考所有权与相机坐标。禁止新建电机 PID、世界姿态 EKF、SLAM、磁北功能、后台服务、第二条 CAN/I2C 输出或新 UI 框架。
3. 固定基座可正置、任意已验证倾斜、倒置。扫描中底座被搬动时受控停扫、重估并重新核对适用域；不实现车载/手持连续基座运动稳定。两轴没有独立 roll 执行能力；不要承诺物理画面自动水平。
4. IMU 在活动 pitch 组件上，不是 base IMU。复用已标定安装矩阵和对时；用**未经 host 相对归零的 game rotation vector**与同一时刻关节角求基座 up。禁止用 `relative_xyzw`、原始 Euler roll 或动态加速度归一化直接当 base tilt。禁止把 tare 当水平标定或自动写入设备 tare。
5. 重力参考不需要磁北。正倒置标签只用于显示/资格，不通过标签翻转电机符号、交换限位或旋转视频；完整几何自动处理方向。
6. 默认平扫 elevation=0（视轴垂直重力）。采用重力平面方位路径，经现有实际外参/LOS 逆解得到连续 yaw/pitch 分支。不能用 `pitch=-roll*sin(yaw)`，不能让 pitch 单独截断而 yaw 继续扫。
7. 由现有唯一轨迹生成器维护**同一个扫描相位及其时间律**，统一产生两轴 q/v/a。根据两轴速度、加速度、jerk、制动与行程一起限速。新数学模块不得另行发送关节命令。
8. 使用运行时编码器标定限位，不用 IMU 判断端点。保留原 hard→soft 内缩，再加至少本包规定的工作留距和动态制动空间；不得降低既有更严格约束。检查整段路径、内部极值和换向，不只检查两个端点。不可达则缩到连续可行段或拒绝该扫描，不扩大行程。
9. 倾斜会改变重力负载，yaw 也可能有重力力矩。以 `up_B` 扩展工况身份，调用 ADR-002.2 已有适用性/局部重估，不假定竖直时的模型在倒置时仍合格；不另手填补偿，不重新做整套 PID 搜索。
10. reticle 中心框/角标不转、不偏移。保留左右共线线段和中间缺口，去掉纵向十字臂，不把左右两段独立旋转。通过投影与显示变换计算屏幕线方向；180°/镜像只应用一次。水平线方向无定义或数据失效时隐藏该线，不显示假的 0°。
11. 参数改变 0 次源码修改、0 次重编译/重新部署。运行时字段暴露、单位/实际值/版本读回沿用既有事务。算法代码更改另建软件版本；不在运动试验中集成其他 PR。工作站原生测试及 ARM64 交叉编译，Pi 不编译。
12. 设备保护继续有效。正常不可达/IMU 无效/质量不合格只结束相关重力扫描或禁用水平指示，沿既有受控制动/负载支撑处理；不是无差别全轴 Fault/掉电。真实危险复用原保护，不等损坏才处理。

## 自动决策与失败处理

程序按文档分类：GRAVITY_INVALID、CALIBRATION_MISMATCH、ORIENTATION_CHANGED、NO_FEASIBLE_ARC、DYNAMIC_ENVELOPE_LIMITED、PLANT_SCOPE_MISMATCH、REFERENCE_INTEGRATION_MISMATCH、MEASUREMENT_LIMITED、HARD_ABORT。输出观测、失败不等式与受影响能力，禁止只说“太难/无法拟合”。

没有合格数据先复查时间/坐标/身份，再调用已有定向采集。采集传输失败同一 case 重试一次；几何错误用离线最小反例定位，不反复驱动机器试不同符号。不得临场放宽指标、加大电流或扫描范围。软件缺陷可正常修复重测，不能将“预算用完”作为放弃定位已复现 bug 的理由。
