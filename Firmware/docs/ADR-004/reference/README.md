# 离线参考工具边界

`geometry.py` 只实现局部数学示例：旋转/重力变换、水平基、带滞回分类、nominal及非nominal外参的点逆解、针孔水平线/显示变换、共线reticle、链式导数、对**外部已提供停止可达区间**的边界检查。

**没有实现**：时间对齐、实际校准、重力窗口估计器、IMU健康检查、连续路径区间证明、标量受限时间律、实际制动包络计算、reference owner/生产接入、HUD消息处理、真实传感器/电机或任何硬件操作。

因此它不是完整阶段1程序、自动调参器或安全控制器，也不能被复制到Python硬件循环替代既有C++核心。Codex应将本包数学契约实现到已有共享核心，并用这些简单算例做交叉检查。

`None`作为无界轴只在例子中表示**明确无界**；真实系统必须区别unknown与unbounded。`stop_interval_inside`接受的停止位移必须来自已验证的控制能力，这个函数不会凭空推导刹车能力。

在包根目录：

```bash
python -m unittest discover -s tests -v
python -m reference.demo
```

只需要Python 3.10+标准库。schema/文档检查报告由打包时另行验证；不要求为了运行这些例子安装任何电机软件。
